Перелік обладнання
1 / 2

Buck 5V

LM2596S понижуючий DC-DC модуль для живлення Raspberry Pi.

  • OUT налаштувати на 5V до підключення Raspberry Pi.
  • IN підключається до Battery + / Battery -.
  • OUT+ йде на Raspberry Pi 5V pad, OUT- на Raspberry Pi GND pad.
Де купити
1 / 2

Buck 12V

XL4015-E1 понижуючий DC-DC модуль для живлення VTX/Fan.

  • OUT налаштувати під напругу VTX/Fan.
  • IN підключається до Battery + / Battery -.
  • OUT+ комутується через relay, OUT- йде на VTX - / Fan -.
Де купити

Реле

1-канальний relay module для вмикання живлення VTX/Fan з GPIO17.

  • DC+ живиться від 12V buck OUT+ (точка до контактів реле, не після NO), DC- від Raspberry Pi GND pad.
  • IN підключається до Raspberry Pi GPIO17 pad.
  • COM / NO комутують плюсову лінію від 12V buck.
Де купити

VTX

Будь-який analog 5.8GHz VTX. Приклад: RUSHFPV RUSH MAX SOLO 5.8GHz 2.5W.

  • Потрібні контакти VIDEO IN, GND і живлення + / -.
  • Напруга живлення має відповідати налаштуванню 12V buck.
  • Антена обов'язково підключена до подачі живлення.
Де купити

Battery 15+V

Будь-яка батарея 15+V. Приклад: 6S2P 24V battery pack.

  • Потрібні Battery + і Battery -.
  • Має витримувати струм VTX/Fan і buck converters.
  • Не підключати батарею напряму до Raspberry Pi.
Де купити

Raspberry Pi Zero 2W

Основний контролер: веб-панель, composite video out і GPIO17 для relay.

  • Використовуються 5V pad, GND pad, TV pad і GPIO17 pad.
  • Живиться тільки від 5V buck.
  • Потрібен Wi-Fi для локальної точки VTX-SETUP.
Де купити

Fan

Опційний вентилятор для охолодження VTX або корпусу.

  • Живиться від 12V buck через Relay NO разом із VTX.
  • Fan + йде на Relay NO, Fan - на 12V buck OUT-.
  • Потрібен, якщо VTX гріється або працює довго.

Безпека

VTX не можна вмикати без антени. Raspberry Pi не можна живити напряму від 6S, VBAT або 12V buck.

  1. Завантаж і встанови Raspberry Pi Imager.

  2. Підготуй термінал. На macOS/Linux використовуй стандартний Terminal. На Windows використовуй WSL або інший Linux shell з доступом до ssh і git.

git --version

  3. Перед записом образу переконайся, що обрав правильну microSD. Raspberry Pi Imager повністю стирає вибраний носій.

    Перед записом

    У налаштуваннях Imager увімкни SSH, задай hostname vtxpi і встанови логін/пароль для першого входу.

Пайка

Ось актуальна схема під поточний код: Raspberry Pi Zero 2 W керує живленням VTX/Fan через GPIO17, логіка HIGH = увімкнути, LOW = вимкнути.

Важливо: спільна земля тут виходить через ланцюг Raspberry Pi GND pad -> VTX GND і 12V buck OUT- -> VTX -. Це працює, якщо на твоєму VTX VTX GND і VTX - є спільною землею. Перевір мультиметром continuity між ними.

Що саме паяти

Паяй по одному рядку і відмічай готове

ASCII-діаграма

ASCII-діаграма 
Battery + -> 5V buck IN+
Battery - -> 5V buck IN-
5V buck OUT+ -> Raspberry Pi 5V pad
5V buck OUT- -> Raspberry Pi GND pad

Battery + -> 12V buck IN+
Battery - -> 12V buck IN-
12V buck OUT+ -> Relay COM
12V buck OUT- -> VTX - / Fan -

Raspberry Pi TV pad -> VTX VIDEO IN
Raspberry Pi GND pad -> VTX GND
12V buck OUT+ -> Relay DC+
Raspberry Pi GND pad -> Relay DC-
Raspberry Pi GPIO17 pad -> Relay IN

Relay NO -> VTX + / Fan +
Relay NC -> not used

Важливо перед увімкненням

  1. Антена VTX має бути підключена до подачі живлення.
  2. Не живити Raspberry Pi напряму від 6S або VBAT.
  3. VTX/Fan не живити від Raspberry Pi 5V.
  4. Використовувати Relay NO, не NC, щоб VTX був вимкнений при старті.
  5. Relay module має спрацьовувати від 3.3V HIGH на IN. Якщо твій модуль не спрацьовує від GPIO Raspberry Pi, потрібен драйвер/транзисторний ключ між GPIO17 і Relay IN.
  6. Перед пайкою DC+ звір напругу котушки реле з маркуванням на самому реле (наприклад JQC3F-12VDC-C означає котушку на 12V). Текст в описі товару може бути шаблонним і не відповідати фактичній деталі. DC+ бери саме з тієї напруги, що вказана на реле (в цій збірці — з 12V buck OUT+), інакше індикатор світитиметься, а реле не клацатиме.
  7. Перевір мультиметром, що VTX GND і VTX - дзвоняться між собою. Якщо ні, потрібен окремий зв'язок 12V buck OUT- -> Raspberry Pi GND pad.

Поточний софт робить так: перед playback ставить GPIO17 HIGH, чекає 300 ms, запускає відео на Composite, після stop/exit ставить GPIO17 LOW.

Налаштування
Результат

Після install.sh пристрій сам створює Wi-Fi точку VTX-SETUP і запускає веб-панель на 10.42.0.1:8080. SSH більше не потрібен для звичайного користування.

Безпека

VTX не можна вмикати без антени. Не вимикай живлення під час завантаження або конвертації відео.

  1. Прошити microSD через Raspberry Pi Imager

    Відкрий Raspberry Pi Imager і пройди setup steps у такому порядку. На скрінах показано приклад: Raspberry Pi Zero 2 W, Raspberry Pi OS Lite 64-bit, hostname vtxpi, user pi. Пароль для user і Wi-Fi впиши свій.

    Завантажити Raspberry Pi Imager
    Перед записом

    Переконайся, що обрав саме microSD. Raspberry Pi Imager повністю стирає вибраний носій.

    Результат кроку 1

    Після завершення запису витягни microSD з ноутбука, встав її в Raspberry Pi і переходь до SSH-підключення.

  2. Встав microSD в Raspberry Pi, подай живлення і підключись по SSH з ноутбука.

    SSH 
    ssh pi@vtxpi.local

  3. Склонуй репозиторій і перейди в папку проєкту.

    Клонування 
    git clone https://github.com/oleksiiasanov/imitator.git
cd imitator

  4. Запусти скрипт встановлення. Він сам встановить пакети, створить .venv, налаштує Wi-Fi точку, composite-вихід, systemd service, GPIO17 relay/power switch і перезавантажить пристрій.

    Встановлення 
    chmod +x install.sh && sudo bash install.sh
    Автоматичне перезавантаження

    Після завершення скрипт перезавантажить Raspberry Pi самостійно. SSH-з'єднання обірветься — це нормально.

  5. Зачекай 1–2 хвилини, поки Raspberry Pi завантажиться після перезавантаження.

    Очікуваний результат

    Raspberry Pi створює Wi-Fi точку VTX-SETUP і запускає веб-панель.

  6. На телефоні або ноутбуці підключись до Wi-Fi точки Raspberry Pi.

    Wi-Fi 
    SSID: VTX-SETUP
Password: vtxplayer
    Нормальна поведінка

    Після встановлення зовнішній роутер для керування не потрібен. Raspberry Pi сама роздає локальну Wi-Fi мережу для веб-панелі.

  7. Відкрий браузер і перейди в панель керування.

    Панель керування 
    http://10.42.0.1:8080
    Фінальний результат

    Відкривається сторінка VTX Video Control. Далі відео, scheduler і playback керуються з браузера.

Як працює автозапуск

  • Raspberry Pi увімкнеться і завантажить систему.
  • Веб-інтерфейс запуститься автоматично.
  • Пристрій почекає задану кількість хвилин до першого запуску.
  • Запустить відео, дочекається завершення і повторить запуск після заданого інтервалу.

Замінити відео пізніше

  • Увімкни пристрій.
  • Підключись до Wi-Fi VTX-SETUP.
  • Відкрий http://10.42.0.1:8080.
  • Завантаж нове відео і дочекайся конвертації.
  • Старе відео автоматично заміниться новим.

Швидкі значення

  • Wi-Fi: VTX-SETUP, пароль vtxplayer.
  • Панель: http://10.42.0.1:8080.
  • Сторінка має назву VTX Video Control.

Що не можна робити

  • Не вмикати VTX без антени.
  • Не вимикати живлення під час завантаження відео.
  • Не вимикати живлення під час конвертації відео.
  • Не подавати 6S напряму на Raspberry Pi.
  • Не змінювати дроти, якщо система вже працює.

FAQ: змінити Wi-Fi без перезапису SD

Використовуй це, якщо змінився роутер, SSID або пароль, і Raspberry Pi більше не з'являється в мережі. Не натискай Write в Raspberry Pi Imager: це перезапише всю SD-карту.

  • Встав microSD у Mac.
  • Переконайся, що boot-розділ відкрився як /Volumes/bootfs.
  • Заміни YOUR_WIFI_NAME і YOUR_WIFI_PASSWORD на реальні дані Wi-Fi.
  • Raspberry Pi Zero 2 W підключається тільки до 2.4GHz Wi-Fi.
  • Перевірений спосіб для цієї збірки: cloud-init recovery через network-config, meta-data і user-data.
Перевірити bootfs 
ls -la /Volumes/bootfs
cat /Volumes/bootfs/network-config
cat /Volumes/bootfs/meta-data
cat /Volumes/bootfs/cmdline.txt
Оновити Wi-Fi через cloud-init 
python3 - <<'PY'
from pathlib import Path
from datetime import datetime

boot = Path('/Volumes/bootfs')
ssid = 'YOUR_WIFI_NAME'
password = 'YOUR_WIFI_PASSWORD'
instance = 'vtxpi-wifi-recovery-' + datetime.now().strftime('%Y%m%d%H%M%S')

(boot / 'meta-data').write_text(f'instance-id: {instance}\n')

cmdline = (boot / 'cmdline.txt').read_text().strip().split()
cmdline = [part for part in cmdline if not part.startswith('systemd.run=') and not part.startswith('systemd.run_success_action=')]
cmdline = [f'ds=nocloud;i={instance}' if part.startswith('ds=nocloud;i=') else part for part in cmdline]
(boot / 'cmdline.txt').write_text(' '.join(cmdline) + '\n')

(boot / 'network-config').write_text(f'''network:
  version: 2
  ethernets:
    eth0:
      dhcp4: true
      dhcp6: true
      optional: true
  wifis:
    wlan0:
      dhcp4: true
      regulatory-domain: "UA"
      access-points:
        "{ssid}":
          password: "{password}"
      optional: true
''')

(boot / 'user-data').write_text(f'''#cloud-config
manage_resolv_conf: false

hostname: vtxpi
manage_etc_hosts: true

- avahi-daemon

  preserve_sources_list: true

  shell: /bin/bash
  lock_passwd: false

  interfaces:
    serial: true
write_files:
- path: /etc/NetworkManager/system-connections/vtx-wifi.nmconnection

  • Якщо cloudwifi.log з'явився, cloud-init виконав runcmd. Тоді перевір SSID, пароль, 2.4GHz Wi-Fi, WPA2 і список клієнтів роутера.

Немає відеосигналу
  • Перевір у /system, чи MPV, FFmpeg, Composite-1 і GPIO17 мають зелений статус.
  • Перевір, чи relay branch вмикає VTX під час playback.
  • Перевір, чи антена підключена до VTX.
  • Перевір, чи VTX не в PIT mode.
  • Перевір band/channel на receiver.
  • Перевір перший розділ FAQ з повною актуальною схемою підключень.

SSH не підключається
  • Почекай 2-5 хвилин після першого boot.
  • Переконайся, що ноутбук і Raspberry Pi в одній Wi-Fi мережі.
  • Спробуй ssh-keygen -R vtxpi.local.
  • Знайди IP через arp -a або сторінку роутера.
  • Якщо Wi-Fi міняли після першого старту, виконай FAQ: змінити Wi-Fi без перезапису SD.

Composite-1 не connected
  • Запусти sudo bash install.sh повторно з папки проєкту.
  • Installer має виставити dtoverlay=vc4-kms-v3d,composite=1.
  • Installer має виставити enable_tvout=1 і sdtv_mode=2.
  • Installer має додати video=Composite-1:720x576@50e.
  • Після зміни boot config потрібен reboot.

Upload або conversion падає
  • Перевір, чи тип файлу підтримується: MP4, MOV, MKV, WEBM, AVI, MPEG, TS.
  • Перевір вільне місце на /system.
  • Перевір, чи ffmpeg доступний на /system.
  • Подивись помилку в Web UI і journalctl -u vtx-player.service -f.
  • Під час conversion playback заблокований — це нормально.
